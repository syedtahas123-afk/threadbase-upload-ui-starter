# Threadbase Upload UI Starter

React avatar upload UI assignment.

## Assignment requirements
- Drag-and-drop and click-to-select image input
- Validate JPEG, PNG, WebP, and GIF files up to 5 MB before uploading
- Preview the selected image and revoke object URLs when replaced/unmounted
- Upload using `FormData` field `avatar` with Axios upload progress
- Do not manually set the `Content-Type` header
